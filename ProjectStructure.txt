                  JAVA OOP MINI PROJECT
============================================================


PROJECT OVERVIEW
----------------
A pet care service platform where:

1. USER / PET OWNER
   - Registers pets
   - Searches services
   - Books services
   - Makes payments
   - Gives reviews

2. SERVICE PROVIDER
   - Accepts/rejects bookings
   - Provides pet care services
   - Updates service status
   - Views assigned bookings

3. ADMIN / MANAGER
   - Manages users
   - Manages service providers
   - Manages services
   - Manages bookings
   - Controls the complete system
